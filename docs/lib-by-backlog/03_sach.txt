PHẦN SÁCH — BẢN CODE HIỆN TẠI
==============================

ĐIỂM ĐÃ ĐỔI
------------

Trước đây màn danh sách tự mở dialog để thêm/sửa/xem. Bây giờ đã tách thành ba
màn hình dễ quản lý hơn:

  BookListScreen     = danh sách, tìm, mở thêm/sửa/xóa.
  BookAddScreen      = form thêm hoặc cập nhật.
  BookDetailScreen   = màn hình xem chi tiết.

Luồng bấm Sách:

Sidebar Sách -> BookListScreen
  -> bookListProvider -> BookRepository -> BookLocalDataSource -> file/asset
  -> List<Book> -> các BookCard.

Luồng bấm một cuốn:

BookCard -> BookDetailScreen(bookId)
  -> bookDetailProvider(bookId) -> getBookById(id) -> Book.

1. DỮ LIỆU SÁCH
----------------

File: lib/features/books/domain/entities/book.dart

L1 `class Book`: tạo khuôn cho MỘT cuốn sách.
L2-L13 constructor: cách tạo một Book. L3-L11 là dữ liệu bắt buộc. `required`
nghĩa là thiếu tên/id/ISBN... thì Dart báo lỗi ngay. L12 để description mặc định
rỗng nếu người dùng không nhập.
L15-L24 là dữ liệu nằm trong Book. `String` là chữ, `int` là số nguyên. `final`
nghĩa là sau khi tạo không được sửa trực tiếp `book.title`; cần tạo Book mới.
L26-L37 `fromJson`: đọc một dòng JSON từ file thành Book. `?? ''` có nghĩa “thiếu
chữ thì dùng chuỗi trống”; `?? 0` là “thiếu số thì dùng 0”.
L39-L50 `toJson`: làm ngược lại để lưu Book xuống JSON. `Map` là dữ liệu theo nhãn,
ví dụ `{'title': 'Clean Code', 'year': 2019}`.
L52-L73 `copyWith`: tạo bản sao Book, chỉ thay field truyền vào. Hiện flow Sách tạo
Book mới trong form nên chưa gọi hàm này.

L70-L73 `_localFile`: chỉ tạo địa chỉ file trong thư mục dữ liệu app, chưa đọc/ghi.

3. PROVIDER MỚI
---------------

File: lib/features/books/presentation/providers/book_provider.dart

L8 tạo nguồn đọc file.
L9 tạo repository dùng nguồn đó.
L10 `bookListProvider`: màn danh sách dùng nó để lấy toàn bộ List<Book>.
L11 `bookDetailProvider`: provider MỚI. `family<Book, String>` nghĩa là mỗi id có
một lần tải riêng. Ví dụ `bookDetailProvider('book-001')` tải đúng book-001.

Provider trả ba trạng thái: đang tải, có dữ liệu, hoặc lỗi. `ref.watch` theo dõi và
tự vẽ lại màn hình. `ref.read` chỉ lấy object để gọi lệnh, không theo dõi. `invalidate`
nói provider bỏ kết quả cũ và tải lại ở lần watch tiếp theo.
